2Create Your Google Sheet Backend
This app stores your data in your own private Google Sheet via Google Apps Script. You'll need to set this up once — it takes about 5 minutes and is completely free.
Step-by-step:
1. Go to script.google.com and create a new project
2. Paste the Code.gs backend code (see README for the full code)
3. Click Deploy → New Deployment → Web App
4. Set "Who has access" to Anyone
5. Copy the deployment URL and paste it below
3Paste Your Apps Script URL
The URL looks like: https://script.google.com/macros/s/…/exec
